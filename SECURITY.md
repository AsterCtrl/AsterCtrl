# Security policy

Security reports should not be filed as public issues. Use GitHub's private
vulnerability reporting form in the repository **Security** tab and include the
affected versions, reproduction steps and impact.

The latest v0.2 prerelease receives security fixes. Legacy v0.1 repositories are
frozen migration inputs and are not supported production releases.

Deployment inventories must not contain passwords, private keys or tokens.
Artifacts and Deployment Locks are verified by digest before activation.
