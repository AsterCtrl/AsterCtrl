# 2026-09-04：v0.2 基础（历史快照）

本文记录 v0.2 切换初期的设计和旧 v1alpha2 生成路径。后续配置驱动收敛已经改变
普通 Linux 的用户模型；CAN/USB 生成 Node、双图和 Lock 段落不能当作当前 v1alpha3
Runtime 功能。当前状态请看 [实施审计](convergence-audit.md)。

## 决策

将旧 Runtime、工具和 Transport 仓库收敛为一个原生 Linux/Zephyr Core 与一个板级
仓库。AimRT 只作为设计参考；默认 Runtime 不保留 AimRT、ROS、XRobot、libxr 或
FreeRTOS 依赖。

## 已实现

- 固定 Module/CoreRef、Status、生命周期回滚、C ABI 和 Zephyr 静态 composition。
- 让静态与动态 Module 都通过唯一 `aster_module_base_t` 执行；`ModuleBase`/`CoreRef`
  是薄 C++ facade，`CoreAdapter` 是 Runtime 侧 Adapter，Package 入口由生成器维护。
- 增加 v1alpha2 双图编译器、确定性 Lock、bounded Protobuf 与 `aster` CLI。
- 建立 Local、CAN/SocketCAN、USB CDC ACM Adapter，以及 Host、`native_sim`、QEMU
  和板级编译门禁。
- 文档统一为 MyST Markdown，Doxygen 只生成 XML 并通过 Breathe 嵌入双语 Sphinx。
- 公共 ABI 与 facade 按组件拆分，聚合头文件只保留兼容导入职责。

## 延后事项与发布约束

PIL、UDP 和生态 Bridge 延后到 v0.3。alpha 仅表示 compile-only；正式 v0.2.0 与旧
仓库归档必须等待两块实板 smoke。USB 真实枚举可以作为明确的未验证项，但协议和
pseudo-TTY 测试必须通过。
